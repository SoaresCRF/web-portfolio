  • Projeto pessoal Em construção desde ago/2026

    Agendamento Multi-Nicho

    Sistema de agendamento para profissionais autônomos: cada profissional tem uma página pública em que o cliente vê os horários livres e agenda sem criar conta.

    • Cálculo de horários livres cruzando disponibilidade, regras por tipo de atendimento, bloqueios e feriados, com datas em UTC.
    • Segurança: JWT com refresh token em cookie httpOnly, senhas com bcrypt, validação com Zod, rate limiting e controle de acesso por recurso.
    • Testes com Vitest e Supertest, CI no GitHub Actions e Docker Compose para o banco local.
    • React
    • TypeScript
    • Vite
    • Tailwind CSS
    • Node.js
    • Express
    • Prisma
    • PostgreSQL
