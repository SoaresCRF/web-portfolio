# 🌐 Portfólio - Versão Web
Meu portfólio pessoal: quem sou, formação, experiência e meus projetos no GitHub.

🔗 **Acesse:** [português](https://soarescrf.github.io/web-portfolio/ "Portfólio em português") · [English](https://soarescrf.github.io/web-portfolio/en/ "Portfolio in English")

> 💡 Também existe uma versão Android deste portfólio: [kotlin-mobile-portfolio](https://github.com/SoaresCRF/kotlin-mobile-portfolio "Projeto no GitHub")

## ✨ Funcionalidades
- Projetos em destaque e lista de todos os meus repositórios públicos do GitHub, atualizada automaticamente.
- Busca por nome, filtro por linguagem e ordenação por data ou A–Z.
- Versões em português e inglês, com link direto para cada seção.
- Design leve, responsivo e acessível.

## 🛠️ Tecnologias
HTML, CSS, JavaScript, Tailwind CSS, Vite, Node.js e GitHub Actions (deploy no GitHub Pages).
